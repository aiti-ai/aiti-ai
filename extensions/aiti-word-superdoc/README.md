## Install

Bundled with **aiti-agent** (`@aiti-ai/pi-web`) — enable it from the in-app extension manager (ExtMan / App Center).

Manual install: place this package at `~/.pi/web/extensions/aiti-word-superdoc/` and reload pi-web.

- Requires `aiti-editor` (the multi-editor arbitration host).
- SuperDoc is AGPL-3.0 — as long as this extension is not installed, pi-web ships zero AGPL frontend components.
