**研发平台（CodeHub）**：云效 / GitHub / Gitee / GitLab 的工作项与代码库统一入口。

- 工作项：搜索、筛选、详情、评论；复制模板、写入提交框、按模板建分支、发送到 AI（当前/新会话）。
- 代码库：代码组/组织 → 仓库 → 分支；收藏、克隆（集成「获取工作区」）、创建合并请求（云效）。
- 双面独立：默认右栏，可浮窗/左栏；最近 + 共享设置。
- AI：`aiti_codehub_*` 工具 + 三个 skills，写操作默认关闭。
- 多账号：同一平台多个账号（别名、分组选择、按账号隔离凭据/收藏/缓存）；GitHub 还可复用本机 `gh` CLI 登录态。
- 鉴权：PAT + OAuth；云效 OAuth 零配置（DCR + PKCE），其余平台按设置页指引登记回调地址。
