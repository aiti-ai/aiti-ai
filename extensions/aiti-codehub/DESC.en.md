**CodeHub** — one hub for work items and repositories across Yunxiao, GitHub, Gitee and GitLab.

- Work items: search/filter/detail/comments; copy templates, write the commit box, create a branch from the template, send to the AI (current or new session).
- Repositories: namespace → repo → branches; favorites, clone (integrated into *Get a workspace*), merge requests (Yunxiao).
- Two independent surfaces: right dock by default, floatable / left dock; Recent + shared settings.
- AI: `aiti_codehub_*` tools + three skills; write tools are off by default.
- Multiple accounts per platform (aliases, grouped picker, per-account credentials/favorites/cache); GitHub can also reuse the local `gh` CLI login.
- Auth: PAT + OAuth; Yunxiao OAuth is zero-setup (DCR + PKCE), the others follow the callback guide in settings.
