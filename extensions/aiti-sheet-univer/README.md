## Install

Bundled with **aiti-agent** (`@aiti-ai/pi-web`) — enable it from the in-app extension manager (ExtMan / App Center).

Manual install: place this package at `~/.pi/web/extensions/aiti-sheet-univer/` and reload pi-web.

Requires `aiti-editor` (the multi-editor arbitration host); server-side format conversion needs LibreOffice (`soffice`).
