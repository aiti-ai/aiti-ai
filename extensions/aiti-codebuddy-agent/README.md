## Install

Bundled with **aiti-agent** (`@aiti-ai/pi-web`) — enable it from the in-app extension manager (ExtMan / App Center).

Manual install: place this package at `~/.pi/web/extensions/aiti-codebuddy-agent/` and reload pi-web.

Requires the cbc CLI on the machine: `npm i -g @tencent-ai/codebuddy-code` (or rely on the npx fallback).
