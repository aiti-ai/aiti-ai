What the plugin put on this server

  • /aiti/aiti-launcher.js — the injected script (comes with the page)
  • /aiti/cockpit.html — the agent cockpit / AI window
  • /aiti/bridge/* — bridge HTTP API used by the launcher
  • /aiti/mcp/* — MCP endpoint, registered with agent CLIs at startup
