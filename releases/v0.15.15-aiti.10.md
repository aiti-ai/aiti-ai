## Highlights

- New extension **aiti-msg-share**: share conversations and messages to pluggable targets
- Four more new extensions: **pi-secret-mask** (deterministic secret redaction), **aiti-testagent** (Java backend debugging), **aiti-git-ops** (whitelisted git write engine) and **aiti-backup** (snapshot backup for large state data)
- **aiti-editor**: selection cards now work across same-origin and cross-origin previews
- Broad bilingual (en/zh) i18n sweep across extensions and the host UI
- File-based release notes pipeline (drafts land in `releases/` and gate tagging)

## Changes

### New extensions

- **pi-secret-mask** (v0.2.3) — deterministic credential detection (regex + checksums + entropy with false-positive guards), stable per-session `[REDACTED:*]` placeholders, deep redact/restore traversal and final-payload leak auditing; the shared engine core is usable by any TS/JS agent host
- **aiti-msg-share** (v0.1.0) — share conversations and messages to pluggable targets
- **aiti-testagent** (v0.1.8) — AI debugging MCP + IDE for Java backends: process scan with one-click bridge attach, tunnel-bridge multi-endpoint management, arbitrary in-JVM modification, Mock & SQL interception simulation, hot updates and diagnostic sampling; 57 tools in 10 groups exposed on demand, fully reversible
- **aiti-git-ops** (v0.1.11) — whitelisted git write engine (checkout precheck / stash / plan breakpoints / audit / changed-topic tracking), consumed by aiti-folder and session-manager
- **aiti-backup** (v0.1.10) — hard-link incremental snapshot backup for large state data, out-of-process execution, crash-safe temp files and keepCount rotation; complements aiti-configs which versions small configs in git

### Extension upgrades

- **session-manager** v0.2.15 — optimistic archive/delete, server-side search-result tag enrichment, full client i18n, zoom-aware dropdowns

- **aiti-devtools** v0.2.2 — pi-locale-aware launcher i18n + dismissed-candidate persistence
- **aiti-extman** v0.1.11 — extension manager polish (search / enable-disable / install / online registry)

- **secret-mask** — shared engine extraction: `secret-mask-core` package now powers both the pi and DSH builds; DSH plugin-market index v1 (format 1, validator-validated)
