## Highlights

- **New extension `aiti-feedback`**: a sanitized in-app feedback form that opens a prefilled GitHub issue — tokens, private IP ranges and home directories are redacted before anything leaves the browser
- **Secret stack v2 lands end-to-end**: an encrypted secret vault with a pre-send credential gate in the composer, shape/context-based secret detection (`secret-mask-core` 0.4), and the DSH port re-aligned on the same core
- **A wider extension surface**: `aiti-sysmon` CPU/memory chips, `aiti-ai-schedule` event triggers (fs-watch / process-exit / webhook), `aiti-editor` and `aiti-sheet-univer` in-app editing, `aiti-folder` live directory watch, `aiti-ai-speek` local TTS, and a layered fleet view for `aiti-subagents`
- **Chat that survives the page**: busy compact requests are parked server-side across reloads, forked sessions keep their live ids, IME composition no longer submits early, and session notice toasts dismiss by tap, swipe or button
- **Top-bar and sidebar density work**: the `sessionStatsInline` slot condenses the stats row into a single flow, and the sidebar dock contract now covers channels, folder and the rest of the dock panels
