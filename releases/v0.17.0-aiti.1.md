## Highlights

- **Upstream baseline 0.17.0**: the host app merges the upstream 0.17.0 release and is re-cut as a single-source repository — host app, 60+ extensions, packages, integrations and the release tooling now live in one tree
- **Survive-restart agent hosting** goes end-to-end: detachable agent processes that outlive a host restart, a detach/start-in-process round-trip in the UI, per-session hosting preference across cold cycles, and a Windows runner (named-pipe endpoints)
- **New extension `aiti-containers`**: container management panel (containers/images/volumes/networks, compose projects, live stats) built for the AI window
- **Secret stack v2**: redaction engine rewrite, encrypted vault with a web UI, and the DSH build aligned at 0.2.0
- **25-provider ACP family is now detachable** — external agents (qoder, codebuddy and friends) can be hosted in wrappers that survive restarts

## Changes

### Survive-restart hosting

- Detachable agent processes: started sessions keep running across pi-web restarts, with a registry of live wrappers, per-session preference markers and a `Start · survive restarts` / `Start in process` pair in the session row menu
- Hosting preference survives cold cycles: a session last hosted detached re-hosts detached on its next open; spawn failure never blocks opening (the marker is a preference, not a lock)
- Windows runner via `Win32_Process.Create` with named-pipe endpoints; POSIX keeps unix-socket endpoints
- `aiti-cmd` terminal sessions stay alive across reloads and restarts; the command dialog is split into three apps (favorites / running / terminal)
- Detachable hosting enabled for the whole ACP family (25 providers), with a replay boundary for adopting external sessions (qoder first) and ACP steer injection gated by driver-scoped probe evidence
- Qoder chat history exposed as a session agent source; codebuddy stream connections hosted in a detachable wrapper

### New extensions & packages

- **aiti-containers** (v0.1.0) — container management for the AI window: four tabs (containers / images / volumes / networks), compose project grouping, log viewing, system usage with 60 s caching, live stats streaming over the event bus (zero new SSE endpoints), three run paths (background / terminal / exec) and a danger-confirmation protocol (UI double-click / API 428 / AI `confirm:true`); bilingual
- **pi-session-search** (v0.1.0) — session search plugin, first npmjs release
- **VS Code extension** — aiti-devtools carrier for VS Code plus an extension-development MCP integration

### Extension upgrades

- **aiti-msg-smart** v0.1.10 — bracket-aware question splitting (matched bracket/quote pairs protect URL queries, ternaries and nested "or" from splitting), soft sentence boundaries (。！…— only split when a question sits on either side), enumerated options with parenthetical notes ("pick A (fast), B (stable)"), quoted questions still get actions, and label truncation never leaves a dangling opener; English question shapes and the file-action row order improved
- **aiti-msg-share** — share-sink extension point (save to local favourites, aiti-prompts snippets), remote audit-catalog overlay consumption, external slot declaration, image/file content handling and kind guards
- **session-manager** v0.2.17 — agent "pi" rows treated as native pi sessions, survive-restart / start-in-process menu wiring, optimistic archive/delete and server-side search-result tag enrichment carried in
- **aiti-model-wizard** — collapsible provider tree + status legend toolbar, full i18n coverage
- **aiti-git-review** / **aiti-editor** — change outline becomes an independent toggle; diff EOL normalization
- **service-tunnels** — ports tab deep-linked from aiti-containers
- **aiti-secret-vault / pi-secret-mask / dsh-secret-mask** — v2 redaction engine, encrypted vault, web vault UI
- **aiti-recovery, aiti-ai-input, aiti-ai-speek, aiti-helper, aiti-channels, aiti-mail, aiti-pair, aiti-quickstart, aiti-models-import** — updated

### Host & tooling

- Bundled extensions reconcile in the background with a failure cool-down (no more blocking startup on a bad extension)
- Interaction popups in the injected launcher attribute items to their agent session and device
- Dev-only crash-fatal harness kept out of every distribution path
- Release pipeline: file-based release notes gating, fork version guard for tags, per-package audit gate before official npm publishes
- The reference demo extension is published to npm without shipping inside pi-web

### Internationalization

- Cross-extension label translation (`translateItemText`), manifest i18n self-registration, ext-host cross-table fallback for missing keys
- Bilingual sweeps across model-wizard, containers, cmd dialogs and more
