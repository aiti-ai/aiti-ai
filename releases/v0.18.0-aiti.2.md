## Highlights

- **Sessions open without spawning**: reading a session never starts an agent process (lazy open), and hosted sessions get a snapshot view, a switch API and an agent badge in the UI
- **New `aiti-interaction` MCP toolset**: a desktop interaction daemon with dialog/cover windows, form input patterns, custom pages and async MCP tools — AI can drive real GUI dialogs end to end
- **Extension updates you can trust**: `aiti-extman` checks updates from two sources with persisted verdicts, and extension metadata (names, taglines, feature groups) is now localized
- **Duplicate bridge registration self-check**: the TUI bridge and the `aiti_*` bundle detect double loading at startup and yield automatically, ending the "Tool conflicts" class of errors
- **Sharper chrome everywhere**: semantic icons on every `aiti-msg-smart` popover action, one line-icon system across the extension list, a compact two-column `aiti-ui-env` panel with restart-proof helper supervision, and provider icons fixed under sub-path deployments
