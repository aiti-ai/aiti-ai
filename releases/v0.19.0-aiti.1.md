## Highlights

- **Shared layer becomes a real package**: every extension now resolves shared helpers through `@aiti-ai/ext-shared` (declared dependency + reconcile install) instead of deploy-time sibling copies — the publish tree is self-contained and ~5.5MB lighter, and the ui icon library resolves at load time via a new host fallback
- **aiti-channels v2**: full management plane (bots aggregation, admin tabs, chat relay, proc runner) plus a Windows-native ACP server TCP transport
- **Detached zcode sessions**: the zcode agent survives a pi-web restart, with live coding-plan quota surfaced through the get_usage capability and across usage surfaces (i18n bucket keys)
- **Process tree grows up**: session names on wrapper/agent rows, node memory breakdown, clean-memory action, kill actions, and click-to-sort headers
- **English-first shared layer**: the entire `extensions/_shared` source (83 files) is now English across comments, logs and dev strings, with locale resources (zh-CN word tables, i18n dictionaries) deliberately preserved
