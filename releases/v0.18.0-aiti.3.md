## Highlights

- **Cursor sessions run on a persistent ACP backend**: new and takeover cursor sessions use the resident `cursor-agent acp` process instead of re-paying a 5-8s CLI warm-up every turn; the legacy print backend stays as fallback
- **Drag-to-reorder toolbar customization**: the toolbar customize panel now supports drag reordering of buttons
- **Session JSON export**: export any pi or external (claude/codex/opencode/…) session to a JSON file from session-manager viewers and row menus
- **Editor & extman upgrades**: large-file info cards with a chunked read-only viewer, `loadMonaco` exposed to third-party providers, and per-extension settings inside the extension manager
- **Richer usage reporting**: provider usage shows the remaining-time ratio next to each reset time and a dedicated credits dimension; agent-badge gains an account quota row
