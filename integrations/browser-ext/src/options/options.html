aiti devtools 设置

任意网页（无需目标应用改造）注入页面内 AI 调试助手。默认关闭——通过白名单站点自动注入，或在 popup 里按需启用。配置保存后刷新页面生效。

AI 目标

选中 pi-web 时自动预填桥地址 = 目标地址 + /aiti（pi-web 同源桥）。首次保存后刷新页面生效。

站点规则

popup 的「⚡ 本页启用（本次）」不受规则限制——任何页面都可手动按需注入。

高级

launcher 连接的 MCP 桥基地址。默认本地独立桥（aiti-bridge，127.0.0.1:8777/aiti）；pi-web 目标通常为「目标地址 + /aiti」（同源桥）。

外部 agent（pi / claude / opencode）经 stdio shim 接入时，把 env AITI_BRIDGE_URL 设为该桥地址（URL 不落 MCP 配置）。
