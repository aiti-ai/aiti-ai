🛠 aiti devtools 设置

任意网页（无需目标应用改造）注入页面内 AI 调试助手。配置保存后刷新页面生效。

launcher 连接的 MCP 桥基地址。默认本地独立桥（aiti-bridge，127.0.0.1:8777/aiti）；可填远程 pi-web 桥。

AI 调试窗 URL。默认与桥同源的 cockpit（本地桥自带）；可指向 pi-web AI 窗。

命中任一正则的 URL 不注入 launcher。

外部 agent（pi / claude / opencode）经 stdio shim 接入时，把 env AITI_BRIDGE_URL 设为该桥地址（URL 不落 MCP 配置）。
